# Soundux Remote

Na instalacao local, a barra lateral do Soundux possui **INICIAR WEB** e **COPIAR LINK**, abaixo de Favorites. O primeiro inicia/abre o painel diretamente. O segundo consulta os IPs atuais e copia o link completo diretamente, sem abrir janela ou seletor. Escolhe um adaptador fisico ativo (Ethernet, Wi-Fi ou USB), priorizando a rota padrao de menor metrica do Windows, e ignora VPNs e adaptadores virtuais. Depois de trocar de rede, clique novamente para copiar o novo endereco. Se o PC estiver ligado a redes locais diferentes ao mesmo tempo, a rede escolhida automaticamente pode nao ser a mesma do celular.

Para reaplicar essa integracao, feche o Soundux pela bandeja e execute `python remote-control/install-sidebar.py`. O instalador copia a interface para `%LOCALAPPDATA%\Soundux-Pouf\dist`, adiciona os botoes e preserva um backup `soundux.before-remote-sidebar.exe`. Como o executavel distribuido embute a interface, o instalador altera somente seu prefixo de navegacao para carregar os arquivos locais, mantendo o tamanho e os offsets do executavel. Nao recompila o aplicativo. Para desfazer, com o Soundux fechado, restaure esse backup sobre `soundux.exe`. Atualizar/substituir o executavel pode exigir reaplicar a integracao. Se mover este repositorio, execute o instalador novamente para atualizar os caminhos dos comandos.

Abra `Controle Celular.cmd`, na raiz do projeto, para usar a janela com os botoes **Iniciar / abrir controle** e **Copiar link do celular**. Inicie o controle, selecione a conexao usada pelo celular e copie o link completo com IP, porta e chave. As conexoes sao atualizadas a cada 5 segundos e tambem antes de copiar. Se houver varias conexoes (Wi-Fi, Ethernet, USB ou VPN), escolha a que permite acesso pelo celular.

Ao trocar de rede ou receber outro IP, copie novamente e abra o novo link no celular. A chave permanece a mesma. O servidor aceita as interfaces disponiveis e atualiza `remote-address.txt` a cada 5 segundos. O celular precisa conseguir acessar o PC pela rede escolhida; o cabo USB precisa fornecer uma conexao de rede, apenas carregar ou transferir arquivos nao basta. Fechar a janela de botoes mantem o servidor em segundo plano.

Controle pelo navegador na rede local, sem banco de dados. Inicie pelo atalho Controle Soundux.lnk. O link de pareamento fica em %LOCALAPPDATA%\Soundux-Pouf\remote-address.txt. PC e celular precisam estar na mesma rede. Nao exponha a porta 3210 na internet.

Requer Node.js 24, Python 3.10 e miniaudio (python -m pip install miniaudio). O servidor inicia um motor Python persistente que reproduz os arquivos diretamente no PC via WASAPI, nas saidas selecionadas na configuracao do Soundux. Nao simula teclado ou mouse. O volume remoto da configuracao e respeitado. A reproducao do controle e independente da barra de reproducao do aplicativo Soundux e nao aparece nela. Se a saida for VB-Cable, selecione CABLE Output como entrada no jogo. A saida padrao de reproducao do Windows recebe tambem o audio local, respeitando localVolume. Se ela ja estiver entre as saidas remotas, nao e duplicada.

Cada clique substitui o som anterior, toca uma vez e para ao fim do arquivo. Parar todos interrompe a reproducao do controle remoto. Nao ha repeticao automatica, playlist ou limite de 60 sons no controle.

Sincronizar salva as abas pelo encerramento normal do Soundux e reabre o aplicativo. Todos os atalhos de sons, parada e push-to-talk sao removidos em cada sincronizacao. Backups ficam ao lado de %APPDATA%\Soundux\config.json. O controle lista a ultima configuracao salva. Nao atribua novos atalhos no aplicativo se quiser manter o teclado desativado.

O token do link autoriza o acesso; compartilhe somente com seus dispositivos. Caso necessario, permita Node.js no Firewall apenas para a rede local. USB no Android funciona se o aparelho fornecer compartilhamento de rede USB; use o IP desse adaptador no PC, porta 3210 e a mesma chave.
